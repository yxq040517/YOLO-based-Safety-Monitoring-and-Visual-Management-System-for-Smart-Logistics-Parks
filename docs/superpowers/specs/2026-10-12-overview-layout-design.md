# 概览布局与可读性优化

用户已确认五项具体改动：压缩横幅、增大字体、突出待处理风险、最近列表展示五条、系统状态前置。

## 布局

保留深色侧栏和青绿色品牌色。页面标题之后是紧凑的系统状态栏，显示模型是否就绪、活动任务、最近一次概览数据更新时间和刷新入口。模型详细原因使用可键盘操作的原生 details/summary 展开。

四个统计卡片先展示待处理风险，并提供直接查看待处理事件的入口。最近事件与趋势图放在主区域，事件获得更多横向空间；最近任务与类型分布放在下一区域。两个列表仅展示五条，保留完整记录链接。

## 字体和交互

表格和表单正文以 14px 为主，说明、日期和状态维持 12–13px，并加深灰色文字。现有响应式断点保留，手机改为单列内容，状态栏允许换行，不通过缩小业务文字适配窄屏。

待处理风险包含 pending、confirmed、processing，与概览统计一致。增加只读 open_only 筛选参数，由风险入口传入；保留事件页的其他筛选和详情参数。

模型状态请求失败不应遮蔽已成功获取的概览数据。更新时间仅在概览数据成功刷新后更新；未拿到数据时显示等待状态。

## 验证

测试事件筛选状态和分页，以及概览数据与模型状态的独立更新。通过现有测试、类型检查和构建。使用合成数据检查 1366×768、1920×1080 和 390×844 布局，确认无页面横向溢出、风险入口有效、状态原因可以展开。
