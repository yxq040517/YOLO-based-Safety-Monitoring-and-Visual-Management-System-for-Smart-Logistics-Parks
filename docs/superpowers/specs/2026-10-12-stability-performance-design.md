## 本轮改动

### 1. 修复概览页柱状图

在 AnalyticsChart 中注册 BarChart，使概览页已有的风险事件柱形序列正常显示。保持现有折线图、环形图、配色和图例。用真实 ECharts 的 SVG 服务端渲染检查柱形输出，避免仅检查 import 字符串。

### 2. 收敛前端轮询

每个 usePolling 实例最多执行一个请求批次并持有一条定时链。可见性或 enabled 状态变化使旧排程失效；手动刷新在请求期间合并为一次后续刷新，并等待该刷新完成。隐藏页面和卸载页面停止自动轮询；已开始的 action 可以完成，但不能重启失效的排程。

验证初次加载、切回前台、暂停/恢复、多次手动刷新、请求失败、卸载，以及任务从运行状态切换为完成状态。继续保持现有 loading、error、refresh 公共接口。

### 3. 隔离异步 API 中的数据库等待

进一步用可重复实验验证上传创建任务及浏览器摄像头初始化中的同步数据库事务对事件循环的影响。仅在验证后，把完整事务及失败清理放到已有的 run_in_threadpool 中执行。Session 的创建、使用和关闭都在同一工作线程，避免跨线程共享 Session。保持队列容量、提交失败状态、权限和上传清理行为。

验证事务等待期间事件循环仍可响应、队列已满时不留下文件或任务、提交失败时任务仍记录为失败，以及摄像头会话结束时释放资源。

### 4. 风险详情切换一致性

风险详情请求切换时取消旧请求，并用请求标识检查结果归属。打开新的详情时清除上一个事件及旧错误；旧请求的 finally 不改变新请求的 loading。避免用户快速切换事件链接时，较慢的旧请求覆盖当前详情。

验证快速切换、关闭详情、请求失败和组件卸载。
